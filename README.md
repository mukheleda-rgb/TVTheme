# TVTheme — واجهة + شاشة توقف لـ Google TV (الإصدار 5)

## البناء
1. افتح المجلد في Android Studio وانتظر مزامنة Gradle.
2. ضع الخط في app/src/main/assets/fonts/ بالاسمين Dubai-Regular.ttf و Dubai-Bold.ttf
3. Build > Build APK(s)  ثم:  adb install -r app-debug.apk

## الميزات
- تقسيم الشاشة (معلومات ربع | تطبيقات ثلاثة أرباع) أو كلاسيكي، مع جهة ونسبة وأحجام قابلة للتعديل.
- تبويب المتجر، أزرار الخلفية / النظام / الثيم، ضغطة مطولة على التطبيق (نقل، إخفاء، تثبيت في المفضلة، إلغاء تثبيت).
- صف المفضلة (حتى 5 تطبيقات).
- تنبيه الأذان: عد تنازلي مباشر + شريط (وصوت اختياري) في الواجهة وشاشة التوقف.
- التاريخ الهجري (مع تعديل ±يوم)، وبطاقة أسعار النفط (برنت + البصرة التقديري بحسب فرق تحدده).
- ثيم تلقائي: نهاراً ثيم وليلاً ثيم آخر.
- شاشة توقف بعرض شرائح وحركة تكبير بطيئة.
- نسخ احتياطي واستعادة للإعدادات (Downloads / الحافظة / ملف).
- إعادة توجيه زر في الريموت (خدمة إمكانية الوصول).

## الجديد في الإصدار 5
- إصلاح انهيار الثيم التلقائي (Prefs صار متسامحاً مع اختلاف نوع القيمة) وصار قسماً عادياً في الإعدادات.
- زر Android TV: تمت إضافة رؤية HOME والحزم في المانيفست + رسالة واضحة إن كانت الواجهة الأصلية معطّلة.
- ضغطة مطولة على زر «الخلفية»: لوحة كاملة (النوع، Bing، المعرض، شريط الشفافية بنسبة مئوية، عجلة الألوان).
- نفس اللوحة داخل الإعدادات > الثيم والخلفيات.

## الجديد في الإصدار 4
- ضغطة مطولة على التطبيق > «تحريك»: تظهر حلقة عائمة تتبع شكل الأيقونة، حرّكه بأسهم الريموت، OK للتثبيت، رجوع للإلغاء.
- شكل الأيقونات من الإعدادات: افتراضي / مربع / دائري / معيّن.
- حذف الإيموجي من كل الواجهة.
- انتقال متتابع سريع بين تبويبي التطبيقات والمتجر (الودجات والتطبيقات وخيارات المتجر).
- الضغط على الوقت أو أي بطاقة (صلاة، فريق، مباريات، نفط، طقس، أخبار) يفتح قائمة خياراتها.
- المباريات: مصدر ESPN أساسي (الدوريات الكبرى) + TheSportsDB احتياطي، ويظهر سبب الخطأ تحت البطاقة عند الفشل.

## شاشة التوقف
adb shell settings put secure screensaver_components com.mokhalad.tvtheme/.SaverService
adb shell settings put secure screensaver_enabled 1

## تفعيل خدمة الزر (اختياري)
adb shell settings put secure enabled_accessibility_services com.mokhalad.tvtheme/com.mokhalad.tvtheme.KeyService
adb shell settings put secure accessibility_enabled 1

## جعله الواجهة الافتراضية
adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
للتراجع:
adb shell pm enable com.google.android.apps.tv.launcherx
